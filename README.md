# Stuckey AI World

Scroll-scrubbed landing page about how Stuckey uses AI specialists, skills, and tools to run the MGA, CoverCore, and StudioGuard.

Built from the [oso95/scroll-world](https://github.com/oso95/scroll-world) engine. Camera motion is Ken Burns zoompan on the clay stills (not a paid Seedance/Monid chain).

## Run

Open `index.html` via any static server (the engine loads clips as blobs).

```bash
python3 -m http.server 8080
```
